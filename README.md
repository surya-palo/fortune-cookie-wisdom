One original fortune-cookie line for a software developer, written by
`main.py` (Python stdlib only) to `/output/entry.txt`:

> The function you named 'temp' will outlive every system you were proud to build.

Entry for the [Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44)
bounty on [make.fun](https://make.fun).

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The program is deterministic: every run writes the exact same bytes,
and it refuses to write anything longer than the 120-character limit.
